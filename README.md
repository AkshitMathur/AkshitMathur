## Featured Projects

**[Energy-Efficient Smart Greenhouse Monitoring & Control System](https://github.com/AkshitMathur/Energy_Efficient_An_IoT_Based_Smart_GreenHouse_Monitoring_And_Control_System)**
IoT system for real-time monitoring and automated control of temperature, humidity, soil moisture, light, and CO₂ levels. Built with ESP32, LoRa, Raspberry Pi 5, and Supabase.
`Python` `ESP32` `LoRa` `IoT`

**[Smart Traffic Controller Using PIC18F4550](https://github.com/AkshitMathur/Smart_Traffic_Controller_Using_PIC18F4550_Microcontroller)**
Intelligent traffic control system using a PIC18F4550 microcontroller, Raspberry Pi 5, and computer vision for adaptive, density-based signal control.
`Python` `Computer Vision` `Embedded Systems`

**[Digital Lock System Using FSM on Spartan-7 FPGA](https://github.com/AkshitMathur/Digital_Lock_System_Using_FSM_On_SPARTAN7_FPGA)**
Secure digital door-lock system implemented in Verilog HDL, driven by a Finite State Machine, deployed on a Spartan-7 FPGA.
`Verilog` `FPGA` `Digital Logic`

**[FreeRTOS Interrupt-to-Task Communication on ESP32](https://github.com/AkshitMathur/FreeRTOS_Interrupt_To_Task_Communication_Using_ESP32_Microcontroller)**
Real-time object detection and counting system demonstrating interrupt-to-task communication, debouncing, dual-core execution, Wi-Fi, and ThingSpeak integration.
`C++` `FreeRTOS` `ESP32`
